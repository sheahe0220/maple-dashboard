# 메이플 대시보드

메이플스토리 개인 대시보드의 배포 판입니다. 본인 넥슨 Open API 키로 본인 PC 에서 돌립니다.

- `latest.json`: 최신 판 번호와 zip 이름. 설치된 대시보드가 켤 때 · 매일 04:00 에 이 파일을 보고 스스로 업데이트합니다.
- `story_share_*.zip`: 배포 판. 압축을 풀고 `설치하기.bat` 을 더블클릭하면 설치됩니다(API 키만 입력).

API 키 · 수집 기록 · 캐릭터 정보는 이 저장소에 들어 있지 않습니다. 데이터: NEXON Open API 제공.
